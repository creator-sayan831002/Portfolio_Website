
# Personal Portfolio Website

A modern, responsive, and visually appealing personal portfolio website built using **HTML5** and **CSS3**. This portfolio showcases my skills, education, projects, and contact information in a clean and professional layout, providing an engaging experience for visitors and potential employers.

## Features

* Responsive and mobile-friendly design
* Professional sidebar profile section
* About Me section highlighting personal background
* Skills showcase with technology icons
* Education timeline with academic details
* Portfolio section displaying featured projects
* Social media and professional profile links
* Direct email and phone contact integration
* Smooth navigation between sections
* Clean and modern user interface

## Technologies Used

* HTML5
* CSS3
* Flexbox
* CSS Grid
* Responsive Web Design
